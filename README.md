# Discord Menü Bot

Discord'a yeni gelmiş olan menü özelliği ile ufak bir altyapı hazırladım güle güle kullanın.

# Kurulum

Yapmanız gereken tek şey `Settings/config.json` dosyasını düzenlemektir.

# Bilgilendirme

Rol alma/verme kodları `twn.js` dosyasındadır.

Discord sunucumuza gelirseniz çok seviniriz. `discord.gg/serendia`
